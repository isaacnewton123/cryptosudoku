# IV — Business Model & Tokenomics

## 4.1 SUDO Token

Utility + governance token for tournament access, staking, voting, cosmetics.

**Key Parameters**

- Name: Sudoku Token
- Symbol: SUDO
- Max Supply: 1,000,000,000 SUDO
- Network: BOT Chain (Chain ID: 677)
- Standard: ERC-20 + ERC-20 Votes

| Utility | Description |
| ------- | ----------- |
| Tournament access | Entry / premium tiers |
| Staking | Revenue-share APY from actual platform revenue |
| Governance | Treasury + parameter votes (post-TGE DAO) |
| Cosmetics / passes | NFT passes, in-game items |

## 4.2 Token Distribution

| Allocation | % | Vesting | Purpose |
| ---------- | - | ------- | ------- |
| Play-to-Earn & Leaderboard | 35% | 4-year linear | Long-term player incentives |
| Investors | 20% | 12–24 month cliff + vesting | Development funding |
| Team & Developers | 15% | 4 years, 1-year cliff | Long-term commitment |
| Treasury & Ecosystem | 15% | DAO-managed | Ecosystem development |
| Liquidity & Market Making | 10% | Immediate | Initial market liquidity |
| Advisors & Partners | 5% | 2-year vesting | Strategic support |

Total: 100%. Investor cliff detail (12 vs 24 mo per tranche) is an open item — see Appendix.

## 4.3 Platform Revenue Streams

| Source | Est. Share | Description |
| ------ | ---------- | ----------- |
| Tournament entry fees | 40% | 5–10% of prize pool |
| Staked duel fees | 25% | 5% of 1v1 duel pot |
| NFT pass sales | 20% | Premium access + cosmetics |
| Sponsorships | 10% | External brand tournaments |
| Premium puzzle licensing | 5% | Exclusive partner puzzles |

## 4.4 Stakeholder Incentives

**Investors**
- Revenue sharing via SUDO staking (APY from real revenue, not emissions).
- Buyback & burn from platform fees (deflationary pressure).
- Treasury governance.

**Developers**
- Team allocation (4-year vesting, 1-year cliff).
- 10% of platform fees as ongoing incentive.
- DAO treasury grants for new features.

**Players**
- Top-100 rewards each epoch.
- Community-pool staking rewards.
- Referral rewards.

**Ecosystem Partners**
- Cross-promotion tournament revenue share.
- Free technical integration.
- In-platform brand exposure.

**Sustainability loop:** fees → rewards + buyback/burn + staking yield → retention → more fee volume. Emissions (35% P2E pool) are linear over 4 years to avoid early inflation shocks.
